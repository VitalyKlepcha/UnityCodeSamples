## Projects

### MoneyCut

A casual lawn mowing game where you drive a mower to cut grass across themed levels. Players manage fuel consumption, collect bonuses, earn in-game currency, and unlock new levels. Includes level types like classic mowing, time-bound challenges, and specific-grass targeting.

### HelicopterProject

An AR helicopter game where you assemble, fly, and perform trick trajectories with different helicopter types. Players progress through an education mode, collect in-game items, advance pilot levels, and unlock certificates. Features include AR plane detection for helicopter spawning, finger-drawn trajectory tricks.
